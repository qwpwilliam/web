JavaScript程序结构：循环与条件

循环：重复执行

for 循环可以让程序重复执行一段代码。下面的循环从 1 数到 10，每次增加 1。

for (let number = 1; number <= 10; number++) {
    // 循环体：每次循环执行这里的代码
}
  • let number = 1：设置初始值。
  • number <= 10：条件成立时继续循环。
  • number++：每轮结束后加 1。

条件：根据情况选择

循环每次数到一个数字时，使用 if...else 判断它是偶数还是奇数。

if (number % 2 === 0) {
    // 条件成立：这是偶数
} else {
    // 条件不成立：这是奇数
}

运行结果：1 到 10

绿色表示偶数，黄色表示奇数。
